Intercept and modify HTTP requests, right in your browser.

THorn HTTP is a free, open-source browser extension to redirect URLs, change headers, mock API responses and inject scripts. Everything stays on your machine: no account, no cloud, no tracking.

Install Read the docs Source code

What you can do

Redirect

Send production URLs to localhost or staging, or swap a script for your local build.

Modify headers

Add, change or remove request and response headers, e.g. CORS or CSP.

Mock APIs

Override REST and GraphQL responses and status codes without touching the backend.

Inject scripts

Run your own JavaScript or CSS on any page.

More rules

Replace strings, query params, cancel or delay requests, change the User-Agent.

Record network

Capture a page's traffic in the side panel and export it as HAR.

Private by design

Your rules live only in your browser. THorn HTTP sends no analytics and talks to no server. Share rules as a JSON file, or as a link that carries the rules inside it (nothing is uploaded).

Coming from Requestly, ModHeader or Charles?

Import Requestly JSON exports, and settings from Charles Proxy, ModHeader, Resource Override and Header Editor.
