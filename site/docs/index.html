Install

Store listings are on the way (Chrome Web Store, Edge Add-ons, Firefox Add-ons). Until then, build it from source:

  1. Get the source code and run bash install.sh then bash build.sh (Node.js 18.18+).
  2. Chrome / Edge / Brave: open chrome://extensions, turn on Developer mode, click Load unpacked and pick browser-extension/mv3/dist.

Your first rule

  1. Click the THorn HTTP icon and choose Open app (or one of the quick rule buttons).
  2. Pick a rule type, e.g. Redirect Request.
  3. Set the condition: URL · Contains · example.com/app.js.
  4. Set the destination, e.g. http://localhost:3000/app.js, and click Save rule.
  5. Reload the page: the request is redirected.

Conditions can match on URL, host or path with Equals, Contains, Matches (regex) or Wildcard. Filters narrow a rule to specific request methods, resource types or pages.

Rule types

  • Redirect Request: send matching requests to another URL.
  • Replace String: replace part of the URL.
  • Query Param: add, change or remove query parameters.
  • Modify Headers: add, override or remove request/response headers.
  • Modify API Response: return your own body and status code for XHR/fetch (REST or GraphQL; for GraphQL match on the operation name).
  • Modify Request Body: change the payload sent by XHR/fetch.
  • Insert Scripts: inject JS or CSS (inline code or a URL), before or after page load.
  • Cancel Request: block matching requests.
  • Delay Network Requests: add latency (capped at 5 s for XHR/fetch and 10 s for other resources).
  • User-Agent: emulate another browser or device.

Header changes and mocked responses are applied by the extension and may not show up in the browser's DevTools Network tab. Use the THorn HTTP DevTools panel to see which rules ran.

Export, import and share

Select rules in the list and click Share → Download rule to get a JSON file. Anyone can add them with Upload rules. Imported rules start disabled; switch them on in the list. Requestly exports can be imported too, and so can settings from Charles Proxy, ModHeader, Resource Override and Header Editor.

Record network traffic

Click Record network in the popup. The current page opens in a new tab with the network side panel recording it. Filter the requests, stop the recording and click Export HAR to save it.

Pause and block list

The switch in the popup pauses all rules. In Settings → Blocked Sites you can list domains where rules never apply.
